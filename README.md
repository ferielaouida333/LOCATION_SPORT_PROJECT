# 🏔️ SportLoc — Location de Matériel de Sport

Projet PHP/PDO orienté objet réalisé en groupe de 3.

**Groupe :** Feriel · Houssem · Zeineb
**Année :** 2024-2025

---

## Installation rapide

### 1. Importer la base de données
- Ouvrir phpMyAdmin
- Créer une base `location_sport`
- Importer **`database_premium.sql`** (données complètes avec photos)

### 2. Restaurer les images
Lancer dans le navigateur :
`http://localhost/LOCATION_SPORT_PROJECT/install.php`

Ce script télécharge automatiquement toutes les photos dans `uploads/`.

### 3. Accéder au site
- **Accueil :** `http://localhost/LOCATION_SPORT_PROJECT/`
- **Catalogue :** `http://localhost/LOCATION_SPORT_PROJECT/public/catalogue.php`
- **Admin :** `http://localhost/LOCATION_SPORT_PROJECT/admin/dashboard.php`
